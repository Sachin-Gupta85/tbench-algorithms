# Levenshtein edit distance

Implement `/app/edit-distance.py`, run as
`python3 /app/edit-distance.py <input.json> <out.json>`. A stub exists.

`<input.json>` is `{"a": "<string>", "b": "<string>"}`. Compute the minimum
number of single-character insertions, deletions, or substitutions that turn `a`
into `b`.

Write `<out.json>` = `{"distance": <int>}`. Exit 0. `/app/data/sample/` has a
worked example.
